=========================================
REST API PLANNING
=========================================

1. What is an API?

API (Application Programming Interface) is a communication bridge between the frontend and the backend. It allows the frontend to send requests and receive responses from the server.

-----------------------------------------
2. What is REST API?

REST API is an API that follows REST principles and uses HTTP methods such as GET, POST, PUT, PATCH, and DELETE to perform operations on resources.

-----------------------------------------
3. HTTP Methods
-----------------------------------------

GET
Purpose:
Retrieve data from the server.

Examples:
- Get all buses
- Get booking history
- Get user profile

-----------------------------------------

POST
Purpose:
Create new data.

Examples:
- Register a user
- Login
- Create a booking
- Make a payment

-----------------------------------------

PUT
Purpose:
Update an existing resource completely.

Examples:
- Update user profile
- Update bus details
- Update driver information

-----------------------------------------

PATCH
Purpose:
Update only specific fields of an existing resource.

Examples:
- Update booking status
- Update payment status
- Update current bus location

-----------------------------------------

DELETE
Purpose:
Delete a resource.

Examples:
- Delete a booking
- Delete a bus
- Delete a route

-----------------------------------------

12. Conclusion
-----------------------------------------
