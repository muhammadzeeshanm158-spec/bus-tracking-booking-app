LOGGING MIDDLEWARE

What is Logging?

Logging means recording application activities.

It helps developers understand what is happening
inside the application.

-------------------------------------------------

Examples

GET /api/v1/users

POST /api/v1/auth/login

PUT /api/v1/buses/5

DELETE /api/v1/bookings/10

-------------------------------------------------

Why Logging?

1. Debug Errors

2. Monitor Requests

3. Track API Usage

4. Improve Security

5. Troubleshooting

-------------------------------------------------

Request Flow

Client

↓

Logging Middleware

↓

Routes

↓

Controller

↓

Database

↓

Response

-------------------------------------------------

Software House Rule

Never use console.log() everywhere.

Use one centralized logging middleware.
