HTTP STATUS CODES MANAGEMENT

What are HTTP Status Codes?

HTTP Status Codes tell the client whether the
request was successful or failed.

-------------------------------------------------

Most Common Status Codes

200 = OK

201 = Created

400 = Bad Request

401 = Unauthorized

403 = Forbidden

404 = Not Found

409 = Conflict

500 = Internal Server Error

-------------------------------------------------

Software House Rule

Never write magic numbers like

200

404

500

inside controllers.

Always use constants.
