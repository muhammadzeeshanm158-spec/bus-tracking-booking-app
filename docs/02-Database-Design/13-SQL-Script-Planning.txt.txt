=========================================
SQL SCRIPT PLANNING
=========================================

1. What is SQL Script Planning?

SQL Script Planning is the process of deciding the correct order for creating the database, tables, relationships, indexes, and initial data.

-----------------------------------------
2. Why is SQL Script Planning Important?
-----------------------------------------

- Prevents Foreign Key errors.
- Maintains proper table relationships.
- Makes database deployment easier.
- Keeps database scripts organized.
- Supports future maintenance.

-----------------------------------------
3. Database Creation Order
